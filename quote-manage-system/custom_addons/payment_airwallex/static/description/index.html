Airwallex Payment Provider

Hosted Payment Page integration for Odoo 17.

Accept cards, Apple Pay, Google Pay, WeChat Pay, Alipay, POLi, BECS DD and more — in AUD, USD, HKD, EUR, GBP and other major currencies — through a single Airwallex merchant account.

Payments redirect to Airwallex's secure hosted page so the merchant stays on the lightest PCI-DSS scope (SAQ-A). Webhooks settle the local payment.transaction state automatically and refunds are issued from the Odoo back office.
